  • Для L1 нужны практическая статика, прямая и обратная кинематика (FK/IK), позиционное управление с ограничениями, проверенный микроконтроллер и остановка.   • S2 и M13 используют эту же ногу для связи с оборудованием, временных меток, воспроизведения записей и аппаратного моделирования (HIL). M19 расширяет одну модель до четырёх/шести ног, проверяет контакты, IMU, перенос веса и классические походки crawl/wave. Отдельного классификатора контакта в основной программе нет.S2 and M13 reuse the leg for the hardware bridge, timestamps, replay and HIL.   • После 4→6 заново измерить массу/COM, повторно проверить коллизии, все 18 калибровок, питание и цикл шины под реальной вычислительной нагрузкой.   • Выбирать привод по рабочему режиму, моменту–скорости, нагреву и измеренной нагрузке, а не по моменту при заблокированном валу. 02 / ROBOTIC ARM

Собственный шестикоординатный манипуляторCustom six-axis robotic arm

ПрошивкаFirmware
  • BOOT: самотест, выходы отключены → READY/FAULT; READY: конфигурация → HOMING/STOPPED; HOMING: медленный поиск нуля → STOPPED/FAULT; MANUAL: свежие команды положения → STOPPED/FAULT; PLAYBACK: одна траектория → STOPPED/FAULT.BOOT: self-test, outputs disabled → READY/FAULT; READY: configuration → HOMING/STOPPED; HOMING: slow zero search → STOPPED/FAULT; MANUAL: fresh position commands → STOPPED/FAULT; PLAYBACK: one trajectory → STOPPED/FAULT.
  • STOPPED очищает очередь и выполняет заранее проверенное ограниченное удержание либо контролируемое опускание; время/ток/температура удержания ограничены. Выход только через явный сброс.   • Внешний контур задаёт кривизну/позу, внутренний управляет положением барабана и ограничивает скорость; ограничитель проверяет ток, температуру, угол и частоту команд.
