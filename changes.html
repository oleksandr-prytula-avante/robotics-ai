Как изменились зависимостиHow dependencies changed

  • S1 позволяет начать работу с ROS до завершения курсов математики и аппаратной части. На S2 добавляются преобразования TF, модель робота и интерфейсы оборудования. Это один модуль M12, разделённый на этапы по 30 и 40 ч.S1 starts ROS before all mathematics/hardware courses finish. S2 later adds TF/model and hardware interfaces. It is one M12 split into30+40h.
  • D1 включает 40 ч статики и расчёта опор и выполняется до L1. D2 включает 58 ч динамики и проверки модели на уже готовом стенде. Для сборки первой ноги не требуется завершать весь модуль M09.D1=40h statics/support checks precede L1; D2=58h dynamics/validation uses the completed rig later. The full M09 is not an entry barrier for the leg.
  • На M11 отрабатывается оценивание состояния по данным инерциального модуля (IMU); затем на M10 создаётся внешний контур управления. LQR/QP из прежнего M11 перенесены в углублённую программу.M11 practical IMU estimation precedes M10 outer control. The old M11 LQR/QP material moves to development.
  • M19 включает общую модель для четырёх и шести ног, а M13 — стенд одной ноги. Время на создание модели повторно не учитывается в M22/M23.M19 contains one four/six-leg model, while M13 covers the single-leg rig. The model is not counted again in M22/M23.
  • M14 теперь классическое зрение и геометрия фиксированной камеры; M18 после него использует тот же набор эпизодов для ML. Поэтому прежняя зависимость CNN до/после M18 заменена выбранной последовательностью.M14 now covers classical vision and fixed-camera geometry; M18 follows it using the same episodes for ML. The former CNN prerequisite ordering is replaced by this selected sequence.
